# About

Caliban is a project created by Pierre Ricadat aka @ghostdogpr (opens new window).

Current maintainers:

  • @ghostdogpr (opens new window)
  • @paulpdaniels (opens new window)
  • @frekw (opens new window)
  • @kyri-petrou (opens new window)

The name Caliban is inspired by the SF novel and tv series The Expanse (opens new window).

Other projects:

  • Shardcake (opens new window) — A Scala library for distributed sharding
  • Proteus (opens new window) — A code-first Protobuf and gRPC library for Scala
  • PureLogic (opens new window) — A direct-style, pure domain logic library for Scala
  • Sage (opens new window) — A modern and fast Redis/Valkey client for Scala
