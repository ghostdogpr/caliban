# 16 — Acquire ordinary and Federation schemas remotely

**What to build:** Acquire ordinary schemas through introspection and Federation schemas through _service using independent finite cold-build budgets and static protected headers.

**Blocked by:** 04 — Compose the client schema and root topology; 07 — Perform one bounded and classified remote GraphQL call; 15 — Classify and own every remote response

**Status:** ready-for-agent

- [ ] Ordinary and Federation acquisition feed the same normalization and composition pipeline as pinned schemas.
- [ ] Acquisition has independent total time, decoded-body, parser, node, and depth limits.
- [ ] Acquisition uses static validated headers only and does not require the runtime environment R.
- [ ] Redirects are disabled by default and any explicitly enabled redirect policy is finite and strips credentials across origins.
- [ ] Concurrent acquisition produces deterministically ordered diagnostics and releases successful siblings if build fails.
